# ✂️🪨📄 Rock-Paper-Scissors Game

A simple Rock-Paper-Scissors game built using [Python].  
This game players (computer) to play the classic hand game in the console/terminal.

## 🚀 How to Play

1. Copy the code from this repository
2. Open VS Code 
4. Paste the code into a file
5. Save the file with the correct extension:
   -.py for Python
6. Run the program and follow the on-screen instructions
7. Choose Rock, Paper, or Scissors and see who wins!

## 🎯 Features

- Simple and interactive gameplay
- One modes: Player vs Computer
- Beginner-friendly code
- Console-based, lightweight and fast

## 💡 Learning

This project helps understand:
- Conditional statements
- Loops
- Random number generation (for computer moves)
- Game logic implementation
